## One open system, from research to execution

**QuantDinger** is an open-source operating system for quantitative trading. It brings research, strategy engineering, backtesting, AI-assisted analysis, live execution, and operational monitoring into one extensible platform.

```text
Research  ->  Build  ->  Backtest  ->  Validate  ->  Execute  ->  Monitor  ->  Improve
```

Built for developers, quantitative researchers, and teams working across **crypto, equities, futures, and forex**.

## The QuantDinger ecosystem

### [QuantDinger](https://github.com/OpenByteInc/QuantDinger)

The core platform and execution engine. Build strategies, run reproducible experiments, connect market data, and operate paper or live trading workflows.

`Python` &nbsp; `Apache-2.0` &nbsp; `Self-hosted` &nbsp; `Multi-market`

### [QuantDinger Web](https://github.com/OpenByteInc/QuantDinger-Vue)

The full browser workspace for research, strategy development, portfolio operations, and system observability.

`Vue` &nbsp; `Research workspace` &nbsp; `Trading operations`

### [QuantDinger Mobile](https://github.com/OpenByteInc/QuantDinger-Mobile)

The official mobile and lightweight web client for monitoring markets, strategies, positions, and alerts wherever you operate.

`Vue` &nbsp; `Mobile` &nbsp; `Lightweight web`

## Designed for serious quantitative work

| Principle | What it means in practice |
| --- | --- |
| **Reproducible by default** | Explicit inputs, historical datasets, experiment records, and comparable results. |
| **Safe execution boundaries** | Paper-first workflows, scoped access, validation, risk controls, and operator confirmation. |
| **Observable operations** | Strategy health, positions, orders, logs, alerts, and execution state remain visible. |
| **AI with guardrails** | Models assist research and analysis while execution stays governed by deterministic controls. |
| **Open and extensible** | Bring your own data, broker, model, strategy code, infrastructure, and automation. |
